# Climate Change Data Analysis

## Overview

A data analysis project exploring environmental indicators across countries and over time using MySQL and Power BI.

## Tools

- MySQL
- Power BI
- SQL

## Analysis

The project covers:

- Descriptive analysis of environmental indicators
- Pairwise relationship analysis using Pearson correlation
- Multivariable analysis using partial correlation

## Dashboard

The Power BI dashboard is available in:

`powerbi/climate_change_analysis.pbix`

## Report

The complete analysis and findings are available in:

`report/CLIMATE CHANGE DATA ANALYSIS.pdf`

## Dataset

The dataset contains 1,000 observations across 15 countries from 2000–2023.
